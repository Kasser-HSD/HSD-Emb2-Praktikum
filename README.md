# Embedded Systems II – Praktikum

Dies ist das Repository für das Embedded Systems II Praktikum der HSD

Melden Sie sich über Moodle an und wählen sie eine Gruppe. Danach können sie das Repository clonen und die versuche bearbeiten.

Bei Fragen melden Sie sich in der Vorlesung oder bei den Praktika bei den Mitarbeitern.

Für die Anleitungen lesen Sie sich die jeweiligen Versuchsbeschreibungen sowie die Anleitung für `git` durch.

Viel Spaß und Erfolg wünscht das gesammte InfLab-Team!
