# Embedded Systems II – Praktikum

Dies ist das Repository für das **Embedded Systems II Praktikum** der *HSD*

Melden Sie sich über [Moodle](https://mdl.hs-duesseldorf.de/course/view.php?id=33) an und wählen sie eine Gruppe.  
Danach können sie das Repository forken und die Versuche bearbeiten.

Bei Fragen melden Sie sich in der Vorlesung oder während den Praktika bei den Mitarbeitern.

Für die Anleitungen lesen Sie sich die jeweiligen Versuchsbeschreibungen sowie die Anleitung für `git` durch.

Viel Spaß und Erfolg wünscht Ihnen das gesammte **InfLab-Team**!

*Resourcen:  
[Arduino IDE](https://www.arduino.cc/en/software/)  
[Arduino Due](https://docs.arduino.cc/hardware/due/)  
[Seeeduino v4](https://wiki.seeedstudio.com/Seeeduino_v4.2/)  
[GroveKit](https://wiki.seeedstudio.com/Grove_System/)*
