# Embedded Systems II – Praktikum

Dies ist das Repository für das **Embedded Systems II Praktikum** der *HSD*

Melden Sie sich über [Moodle](mdl.hs-duesseldorf.de) an und wählen sie eine Gruppe.  
Danach können sie das Repository Clonen und die Versuche bearbeiten.

Bei Fragen melden Sie sich in der Vorlesung oder in den Praktika bei den Mitarbeitern.

Für die Anleitungen lesen Sie sich die jeweiligen Versuchsbeschreibungen sowie die Anleitung für `git` durch.

Viel Spaß und Erfolg wünscht Ihnen das gesammte **InfLab-Team**!

Resourcen:  
[Arduino](www.arduino.com)  
[SeeedStudio](www.seeedstudio.com)  
[GroveKit](www.seeedstudio.com/grove)
